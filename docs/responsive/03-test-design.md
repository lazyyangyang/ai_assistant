## 数据与准备

准备两个隔离测试账号，验证数据归属；简历准备无敏感信息的 PDF、TXT、DOCX，以及损坏文件、同名文件和超长中文文件名。大文件按后端实际限制测试，不把未经确认的上限写成既有规则。

会话夹具包括空列表、单会话、50 个会话、300 条长消息、长 URL、连续英文、宽 Markdown 表格和代码块；JD 包含空值、超长字段、完整结构化结果；报告包含正常、无反馈、非法 JSON 和接口失败。

SSE 夹具以实际协议构造：中文 UTF-8 跨块、文本片段、结构化事件、结束事件、半途断连与主动取消。使用固定日期、固定文案和固定消息 ID 生成视觉基线，截图前等待字体与布局稳定。

后端集成使用专门测试数据库和账号，记录目标后再进行必要初始化，不操作日常数据库。真机通过受信任 HTTPS 同源地址访问，确认 Origin 与 Cookie 配置；仅做前端模拟时不启动真实 AI 调用。

## 性能和可访问性验收

在同一设备、同一浏览器、同一网络配置下，对改造前后各重复三次，记录中位数；真实模型延迟与前端交互耗时分开。300 条长消息滚动时无持续白屏或输入阻塞；打开菜单、面板目标为 200 ms 内出现交互反馈，此值为项目目标而非已测结果。

使用键盘与真机 VoiceOver 或 TalkBack 检查导航、面板、输入、录音状态和错误提示。普通文本对比度目标 4.5:1，较大文字 3:1；按钮不能只靠颜色区分状态。减少动画设置开启后避免不必要的持续动画。逐块流输出不应持续打断读屏。
