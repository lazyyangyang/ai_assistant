# SMIL 首次启动与多标签页对比（2026-10-30）

## 范围和方法

- 当前生产构建、本地 Vite preview、Chrome 有界面独立测试窗口，1365×1100，禁用 HTTP 缓存。未启动后端或调用模型，未修改产品源码。
- 1 / 4 / 8 个页面同时导航；正常 CPU 与 CDP 4 倍降速各三轮，共 18 组（78 次页面加载）。每组 load 后观察 4.5 秒；多页组另切换一次页面观察 1.2 秒。
- 每 50 ms 采样 SVG 腿部 getBBox、getTotalLength、SMIL 时钟及暂停状态；记录 rAF 帧间隔、FCP、长任务、可见性及错误。采样会强制部分布局，存在测量开销，几何变化不等同逐像素录像。
- “首次变化延迟”从首次采样到腿形变化，采样分辨率约 50 ms；不等于从导航开始或从屏幕首次可见开始。
- 尽管使用有界面窗口并移除三个后台优化禁用参数，所有页面 document.visibilityState 仍报告 visible。因此这是多页面并发负载测试，**不能代表日常浏览器隐藏标签页的节流、挂起或恢复行为**。
- 只有三轮，不是容量上限、长时间稳定性或真实手机验收。未测试开发服务器/HMR、慢网、线上 CDN。

## 结果（中位数，毫秒）

| CPU 条件 | 同开页面数 | FCP | 首次腿形变化延迟 | 初始 4 秒最大 rAF 间隔 |
| --- | ---: | ---: | ---: | ---: |
| 正常 | 1 | 156 | 579.5 | 12.2 |
| 正常 | 4 | 176 | 587.0 | 12.2 |
| 正常 | 8 | 220 | 622.9 | 12.3 |
| 4 倍降速 | 1 | 576 | 285.2 | 424.1 |
| 4 倍降速 | 4 | 596 | 298.9 | 436.3 |
| 4 倍降速 | 8 | 648 | 298.0 | 430.4 |

正常 CPU 下，从 1 页到 8 页首次变化中位延迟增加约 43 ms，首屏增加 64 ms，没有观察到随标签数成倍增长。首轮浏览器冷启动有离群值：单页 FCP 1844 ms、首次腿形变化延迟 1600 ms；保留在原始结果中，没有当成动画稳定启动耗时。

正常 CPU 的多数轮次，FCP 后到首次腿形变化仍约 0.55–0.60 秒。在此期间 rAF 正常推进、SMIL 时钟增加、animationsPaused=false，但采样路径高度保持不变。当前完整动作周期为 0.64 秒，支持“首个 SMIL 周期初始化/更新时序异常”的判断，不能据此认定整个页面主线程被阻塞 0.6 秒。

4 倍降速的约 0.42–0.44 秒最大帧间隔主要落在首次绘制之前/附近，首屏本身更迟；首次腿形变化大多已发生于 FCP 之前。**首次变化指标变小不代表低性能设备更顺畅**。FCP 后一秒以后，正常 CPU 各组最大帧间隔为 6.4–7.1 ms；降速组最高为 48.5 ms。rAF 测量不是实际屏幕呈现的帧率保证。

本轮无捕获的页面错误；未发现持续停滞。不能推断零内存泄漏或无限标签页稳定。

## 原因分析与对照

1. 当前实现的身体/跑道使用 CSS 动画，四肢使用 SVG SMIL，两套动画时钟独立；手动暂停由 useLayoutEffect 同时控制。
2. 实测在路径静止时，时钟与页面帧回调可继续运行，且未处于主动暂停状态。表现更接近 Chrome 中首次 SMIL 路径更新时序，而非后端等待或动画资源下载。
3. 浏览器首次启动与 React、样式、布局初始化还会带来另一类开销；降速时观察到约 260–295 ms 的初始长任务。没有浏览器性能追踪调用栈，不能把这些全部归因到 SMIL。
4. 临时对照构建中，仅在已暂停时才调用 unpauseAnimations 仍出现约 0.62 秒首周期等待，排除了“无条件 unpause 是唯一原因”的假设。
5. 将 begin 改为 indefinite 并在 layout effect 中显式 beginElement、或推迟到一次 rAF 后启动的两种临时构建，1.8 秒窗口内未采样到腿形变化，未形成可靠修复。**未将这些试验写入产品代码**。

因此可以确认现象及多页面下的量级，但 Chrome 内部的精确初始化原因仍未确认。不建议凭猜测加固定延时；后续修复需要针对 SVG 挂载/SMIL 启动时机做独立对照与跨引擎回归。

SVG SMIL 文档时间线与 SVG 加载/起始时刻有关，规范参考：
https://svgwg.org/specs/animations/
